# 最简剪辑台（lite）

独立轻量页面：**识别 → 台词 → 关键词/剧本剪 → 取片**，一条链走完。按仓库铁律做成独立新服务，
不修改原工作台（61810）与分析 API（61812）的任何代码，能力全部来自 61812 的既有接口。

## 启动

1. 先双击仓库根 `启动.bat`（拉起分析 API 61812；61810 工作台可开可不开）；
2. 再双击本目录 `启动简易台.bat`（61814），浏览器会自动打开 <http://127.0.0.1:61814>。

61812 没启动时页面顶部会红字提示，不会误报其他错误。

## 为什么要有这个服务

61812 未开放 CORS，网页直接跨端口调用会被浏览器拦；本服务（61814）把静态页和
`/api/*`、`/media` 反向代理到 61812，页面与接口同源，一个端口就能用。

## 文件

| 文件 | 作用 |
| --- | --- |
| `server.py` | FastAPI 静态页 + 反向代理（默认 127.0.0.1:61814，可用环境变量 `LITE_PORT`/`LITE_UPSTREAM` 覆盖） |
| `index.html` | 单文件页面（无框架、无构建） |
| `启动简易台.bat` | 用项目自带 runtime 启动本服务并打开浏览器 |
