# Shotcut 视频剪辑软件 — 启动方式与使用说明

> Shotcut 是一款**免费开源、跨平台**的视频剪辑软件（GPL v3 协议，源码：https://github.com/mltframework/shotcut ），
> 界面和操作方式接近剪映（预览窗 + 时间线 + 刀片分割 + 导出），适合本项目"快速裁剪、保留有用片段"的日常剪辑需求。
> 本目录已内置便携版（随项目文件夹一起走，换电脑无需重新下载）。

## 一、软件位置与启动

### 主程序路径

```
ai-video-studio\Shotcut\Shotcut\shotcut.exe
```

### 启动方式（任选其一）

1. **桌面快捷方式**（推荐）：桌面已创建「Shotcut 视频剪辑」图标，双击即可打开；
2. **直接双击** `shotcut.exe`；
3. 命令行启动：`"E:\aijianjishiping\ai-video-studio\Shotcut\Shotcut\shotcut.exe"`。

> 便携版免安装、免注册，删除整个 `Shotcut\` 文件夹即可卸载，不留系统残留。

如需手动切换：菜单 **设置 → 语言 → 中文（简体）**，重启生效。

## 三、基本使用流程（裁剪视频）

1. **打开视频**：菜单「文件 → 打开文件」，或直接把视频文件拖进窗口；
2. **播放定位**：用预览窗下方的播放条播放，找要剪的位置；
3. **分割**：播放到要切开的地方，点工具栏 **✂️ 刀片图标**，视频在播放头处切成两段；多切几刀可分成多段；
4. **删除不要的段**：在时间线上**点选**要删的片段（选中会高亮）→ 按 **Delete 键**；
5. **导出**：菜单「文件 → 导出 → 导出视频」→ 预设选 **H.264 / MP4** → 点「导出」。

> 口诀：**打开 → 播放 → 刀片切 → 点选删 → 导出**。时间线上剩什么，导出就是什么，不会丢片段。

## 四、注意事项

### 1. 导出位置
- 导出窗口最上方有「导出到文件夹」选项，**默认是系统"我的视频"目录**（`C:\Users\<用户名>\Videos\Shotcut`）；
- **建议导出前手动改**到素材目录（如 `E:\aijianjishiping\素材\`），方便查找；
- 本项目的成片归集约定见 `部署方案.md`（批量剪辑产物进 `素材\<文件夹>\批量\`）。

### 2. 导出格式建议
- 日常裁剪选 **H.264 (libx264) + MP4**：兼容性最好（手机/电脑都能播）；
- 若要**无损**（不重新编码、秒级导出），可用「无损/无重编码」预设（依赖素材本身编码）；
- HEVC/H.265 素材：Shotcut 新版原生支持；若预览黑屏，改用 H.264 导出即可。

### 3. 首次打开性能
- 大视频（几 GB）首次打开要建立索引/缩略图，会稍慢，属正常；
- 时间线缩放：`Ctrl + 滚轮`（或工具栏放大镜图标）。

### 4. 与项目 AI 工具的关系
- Shotcut 是**人工精剪**工具（手工刀片分割、点选删除）；
- 项目的 AI 场记单/向量检索/批量剪辑在网页端 `http://localhost:8003` 使用，两者互补：
  - AI 批量去片头片尾 → 网页「批量剪」；
  - 精确到镜头的精细手工剪辑 → 用 **Shotcut**。

### 5. 软件来源与更新
- 便携版版本：v26.8.1（win64），下载自官方 GitHub Release（镜像：`mirror4.lzu.edu.cn/github-release/mltframework/shotcut/LatestRelease/`）；
- 需要升级：从上述镜像下载新版 zip，解压覆盖本目录即可（个人设置保留）。

## 五、常见问题

| 问题 | 解决 |
|---|---|
| 打开视频黑屏/无图像 | 视频是 HEVC/特殊编码，导出选 H.264，或用「文件 → 打开」重新选择 |
| 导出的视频找不到 | 看导出窗口「导出到文件夹」写的是哪；默认在 我的视频\Shotcut |
| 界面变回英文 | 设置 → 语言 → 中文（简体），重启 |
| 时间线看不到片段 | 确认视频已添加到时间线（打开后自动在 V1 轨道）；放大时间线（Ctrl+滚轮） |
| 删错片段 | 菜单「编辑 → 撤销」（Ctrl+Z） |
