# AI 字幕剪辑工作台

根据声音生成字幕、并按台词剪辑视频的本地离线工具。

## 功能

- **字幕识别**：本地语音大模型（Paraformer + VAD + 标点 + 说话人区分），把视频里的声音转成带时间戳的字幕
- **自动加字幕**：识别结果直接烧录进画面，或导出 SRT
- **一句话剪辑**：输入关键词或一句话，自动找出字幕里对应的时间区间并剪出成片
- **说话人区分**：标注每句话是谁说的，可按说话人筛选剪辑
- **手动精修**：内置剪映式时间线（分割 / 删除 / 字幕烧录）

## 启动

双击 `启动.bat`（需要先完成部署，见下方）。会自动打开：

- http://127.0.0.1:61810 —— 剪辑工作台（上传/选择视频 → 识别 → 勾台词 → 裁剪）
- http://127.0.0.1:61812 —— 分析服务（整个文件夹批量分析 → 台词 JSON → 关键词/剧本剪辑）

关闭：双击 `关闭.bat`。

## 目录分析（台词 JSON）

分析服务里输入视频文件夹路径点「分析」，每个视频会在**同目录**生成 `视频名.clip.json`：

```json
{
  "video": "第1集.mp4",
  "duration_sec": 2200.5,
  "lines": [
    {"start": 1.2, "end": 4.5, "text": "你当初是不是看到我爸的钱了", "speaker": "女人"}
  ]
}
```

后续剪辑（关键词 / 剧本）都读取这个 JSON，按时间区间精确剪出。

## 部署（新机器）

1. 整个文件夹复制过去（`runtime/`、`modelscope-cache/` 一起复制即为全部依赖与模型缓存）
2. 双击 `启动.bat`

如需从零安装：`python -m venv runtime` 后 `runtime\Scripts\pip install -r requirements.txt`（国内加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`），首次启动会自动从本地 modelscope-cache 读取模型。
